# Revisão crítica — M4 e M5 (site, calculadora TS, perguntas guiadas)

Revisor independente com as personas gestor municipal do interior (celular, 3G emulado), jornalista e
especialista em acessibilidade, mais uma leitura da camada de comunidades. Também houve crítica visual
própria por screenshots (designer). Medições: Playwright com 3G emulado (400 ms RTT, ~400 kbps), axe-core,
percurso só com teclado, 320 px e zoom de 200%.

**Verificado sem problema:** JS dentro do orçamento; texto legível antes de 1,5 s no 3G; contraste aprovado
pelo axe; foco visível; link de pular; rótulos em todos os campos; `prefers-reduced-motion`; títulos sem saltos;
estados "sem dado" bem explicados na saúde, na calculadora e no índice (que se recusa a publicar ranking
incompleto).

## Crítica visual própria (antes da revisão)

| Achado | Correção |
|---|---|
| Navegação principal invisível no desktop (conteúdo de `<details>` fechado não pode ser forçado por CSS) | Navegação separada para desktop |
| Ficha pesava 75 KB comprimida (mapa repetido em cada página) | SVG base compartilhado + contorno destacado: 8 KB |
| Município pequeno invisível no localizador | Anel de destaque |
| Ficha com 10.000 px no celular, tabela de 5 colunas espremida | Números-chave no topo, tabela empilhada em cartões, fontes recolhíveis |
| Card OG vazando (Satori não desconta padding) | Contêiner interno com tamanho explícito |
| Mapa com Lighthouse 68 (MapLibre bloqueando 1,1 s) | MapLibre sob demanda + prévia estática: 91 |
