# Territórios com Sede

Observatório de água e saneamento do [Instituto SDW](https://institutosdw.org).

> *Que ninguém adoeça por causa da água que bebe.*

No Brasil, a sede tem endereço. E quase sempre ele está fora das estatísticas. Esta plataforma reúne
dados públicos de saneamento e saúde para **ver** a situação de cada município, **calcular** quanto o
território economizaria eliminando as doenças ligadas à água e **agir** onde o investimento gera mais impacto.

- Como rodar: `make setup && make data UF=BA && make dev` (detalhes em `CLAUDE.md`)
- Especificação: `docs/SPEC.md` · Metodologia: `docs/METODOLOGIA.md` · Fontes: `docs/DATA_SOURCES.md`
- Publicação e manutenção: `HANDOFF.md`
